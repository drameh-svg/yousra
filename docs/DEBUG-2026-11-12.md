# Search, similar products and retailer links — 2026-11-12

Confirmed on the source backing https://soutrawithyusra.vercel.app/:
- `/search` was filtering 30 curated references rather than using live discovery.
- Category matching included every reference because `aesthetic !== undefined` was always true.
- Aesthetic/brand/alternative pages used static subsets, including fallback products from unrelated brands.
- Similarity forced up to eight results without a category/evidence threshold; unknown attributes contributed.
- Some curated URLs were retailer homepages or placeholders.
- Search discovery replaced initial cached matches even when a batch was empty.

Fixes:
- Search submits to the live search-results flow; collection landing pages use a shared live grid.
- Preserve cached search IDs; analyze only newly discovered candidates.
- Infer plural category names and include retailer/brand wording in lexical matching.
- Restrict similarity to the target garment category, using weighted content vectors,
  known attributes and material/silhouette words. Exclude duplicates and weak matches.
- Reject homepage/category/social purchase links. References offer current-listing search.
- Validate retailer destination redirects when accessible; reject expired products and landing-page redirects.
- Keep reference/test items out of real discovery. Preserve account restrictions and quota limits.
- Surface saved budget on search results and link directly to server-backed preferences.
- Add public nonsecret deployment revision to `/api/health` for release verification.

Local verification:
- 25 backend tests pass, including URL validation, similarity, cached-search retention,
  plural searches, private saves, restrictions, feed paging and quota enforcement.
- Lint and production build pass.
- Browser test passes: Search → live results → product → target-category suggestions;
  reference homepage links cannot be used as purchase links; live categories and mobile overflow checked.

External retailer restrictions, removed products and provider limits can still prevent
individual results. These must be reported accurately rather than replaced with fabricated listings.
